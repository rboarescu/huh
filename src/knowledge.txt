# Curated knowledge for `huh explain`. Parsed by src/knowledge.rs.
#
#   @prog [subcommand...] | what it does        starts a section
#   !single      options like -name are one option (no -abc splitting): find, java
#   !oldstyle    a first word without a dash may be bundled options: tar xzf, ps aux
#   !first       words after the first option are not positional (find)
#   !wrapper     the program only wraps another command
#   pos: a ; b ; c...                           meanings of positional words, in order
#                                               ("..." on the last repeats it)
#                                               ">LABEL" = the rest is a command (words);
#                                               ">>LABEL" = the rest is a command line (string)
#   -a, --all LABEL | meaning                   an option; LABEL (upper-case) means it takes a
#                                               value, [LABEL] an attached optional value.
#                                               The meaning may use LABEL for the value.
#   key= | meaning                              a key=value operand (dd, make)
# Subcommand sections inherit the options of their parent section.

@ls | List the files and folders in a folder
-l | show details: permissions, owner, size and date
-a, --all | include hidden files (names starting with a dot)
-A | include hidden files, except . and ..
-h, --human-readable | show sizes like 1K, 234M, 2G
-R, --recursive | also list everything inside sub-folders
-t | sort by modification time, newest first
-S | sort by size, largest first
-r, --reverse | reverse the sort order
-1 | one name per line
-d, --directory | list the folder itself, not what is inside it
pos: the file or folder to list...
